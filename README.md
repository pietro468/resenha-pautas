# Pautas do Resenha Rentável

Artigos escritos automaticamente todo dia, em 3 turnos (manhã, tarde e noite), para o blog resenharentavel.com.

- `linha-editorial.md`: manual de redação do blog.
- `ROTINA.md`: passo a passo diário do redator automático.
- `artigos/`: uma pasta por dia, com uma pasta por artigo (.md + imagens).
- `index.json`: lista que o site lê para importar os artigos novos.
- `ferramentas/publicar.py`: confere os artigos e atualiza o `index.json`.

O site importa pelo plugin "Importador de artigos Resenha", em Ferramentas, Importar artigos Resenha, no quadro "Automático pelo GitHub".
